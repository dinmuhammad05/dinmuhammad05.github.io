Kodla — web dasturlashni o‘zbek tilida noldan o‘rgatuvchi interaktiv sayt. JavaScript qismi javascript.info o‘quv dasturi tuzilishidan ilhomlangan, keyin esa backend, frontend va DevOps mavzulari bilan davom etadi.

Saytning asosiy xususiyati — misollarni o‘qib qolmasdan, shu yerning o‘zida o‘zgartirib ishga tushirish mumkin: 559 ta kod maydonchasi natijani darhol ko‘rsatadi.

Texnik tomondan sayt tashqi kutubxonasiz, sof HTML, CSS va JavaScript. Darslar alohida blok formatidagi fayllarda saqlanadi, kichik Node.js generator esa ulardan bir xil dizaynli sahifalar yasaydi — yangi mavzu qo‘shish bitta fayl yozishdan iborat.
